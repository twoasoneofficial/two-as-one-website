# TWO AS ONE — Public Website

A responsive static marketing website for TWO AS ONE, designed for deployment on Cloudflare Pages.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive layout and brand styling
- `script.js` — mobile navigation and footer year

## Before public launch
1. Replace the temporary “Ask about the game” email CTA with the confirmed one-time game checkout URL.
2. Confirm that `hello@twoasone.co.za` is a working inbox before publishing the contact links.
3. Add approved brand logo and product imagery if available.

## Cloudflare Pages
Framework preset: None
Build command: leave blank
Build output directory: `/` (root)
The site is plain HTML, CSS and JavaScript; no build step is required.
